Ojanuan Em desenvolvimento

Plataforma de acompanhamento terapêutico que liga psicólogos e pacientes. O profissional agenda consultas, conversa por chat, acompanha a autoavaliação diária de bem-estar do paciente e gera o livro-caixa para o Carnê-Leão.

Como é construído

  1. Interface Vercel

    React 19, TypeScript, Tailwind e Recharts. Mobile-first e instalável como PWA. Dois perfis, profissional e paciente, com chat por polling e autoavaliação diária com gráficos.

  2. API REST Render

    NestJS com validação de DTOs, login com JWT, convites por token e documentação em Swagger. Um script de testes de integração E2E cobre autenticação, convites, chat e relatórios.

  3. Banco de dados

    PostgreSQL com Prisma e migrations versionadas. O conteúdo clínico, como chat e anotações, é cifrado com AES-256-GCM antes de ser gravado. Exportação e exclusão de dados do titular, pensadas para a LGPD.
